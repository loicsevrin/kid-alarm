# Kids Alarm clock with a tft display

## Setup

- Buy an ESP32-Cheap-Yellow-Display, many libs and examples are available on <https://github.com/witnessmenow/ESP32-Cheap-Yellow-Display>
- Use arduino IDE
- Install dependencies 
  - `XPT2046_Bitbang_Slim`
  - `TFT_eSPI`
  - `NTPClient`
  - `ArduinoJson`
- Follow the instructions in [this SETUP](https://github.com/witnessmenow/ESP32-Cheap-Yellow-Display/blob/main/SETUP.md)
  - Do not forget to copy the file User_Setup.h to the libraries\TFT_eSPI Arduino folder. This sets up the library for use with this display.
